# StoreCopy AI

A simple AI-powered product copy generator for ecommerce sellers.

## Features
- Generate product descriptions in seconds
- Support multiple languages
- Create headline, bullet points, and ad copy
- Mobile-friendly landing page
- No backend required for the demo version

## How to run locally
Open `index.html` directly in a browser, or serve with a simple local server:

```bash
python3 -m http.server 8000
```

Then open:

http://localhost:8000

## Demo status
This is a fast MVP landing page and copy generator with no external API dependency, designed to work immediately on mobile and desktop.
